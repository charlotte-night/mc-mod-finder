社区中继（可选，用于把 B 站搜索结果直接列出来）

贴吧与 B 站都不允许网页直接读它们的接口，唯一能真正取到社区条目的办法是自己有个中继。 两种都行：自建 RSSHub（docker run -d -p 1200:1200 diygod/rsshub，然后填 http://127.0.0.1:1200）， 或一个 CORS 转发前缀（形如 https://xxx.workers.dev/?url=，地址里带 {url} 也行）。 公共实例实测当前几乎都返回 503，所以默认关闭、也不预置任何一个。 注意：RSSHub 没有贴吧路由，所以中继只能带来 B 站条目。
